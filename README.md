# EditAura - Collaborative Code Editor 🚀

Real-time collaborative code editor with built-in chat. Code together with your team instantly!

## ✨ Features

- 🔐 **User Authentication** - Simple username-based login
- 💬 **Real-time Chat** - Built-in chat for team communication  
- 👥 **Live Presence** - See who's online in your workspace
- ⌨️ **Collaborative Editing** - Code syncs in real-time
- ▶️ **Code Execution** - Run JavaScript & Python code
- 🎨 **CSS Playground** - Live CSS styling
- 💾 **Auto-save** - Code automatically saved

## 🛠️ Tech Stack

- **Backend**: Node.js + Express + Socket.IO
- **Frontend**: HTML5, CSS3, Vanilla JavaScript  
- **Real-time**: WebSockets (Socket.IO)
- **Database**: JSON file-based storage
